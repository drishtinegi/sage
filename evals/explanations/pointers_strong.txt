Pointers in C are variables that store the memory addresses of other variables. Declaring a pointer only creates the pointer variable itself; it does not allocate memory for the data it points to, which must be done separately. You can initialize a pointer using the address-of operator to reference an existing variable. To access or modify the value stored at that memory location, you use the dereference operator. Pointer arithmetic is also type-aware, meaning incrementing a pointer advances it by the size of its data type in bytes.
